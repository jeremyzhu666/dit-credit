## 🎴 名片生成器 · 使用说明（DIT Credit）

### 一步到位：填字段 → 预览 → 下载 JPG
1. 打开 **名片工具地址**
2. 左侧填字段（默认值已帮你预填，直接改就行）：
   - **外观**：背景色 / Logo 文字（KK）/ 标题色 / 内容色
   - **第一部分**：工作室名称（默认 *KK SH*，按需改为本场 DIT Team）
   - **第二部分**：项目名称（默认 *Commercial - AUDI*，如 *EV - AUDI E7X Launch PV*）
   - **第三部分 Talented Crew**：三行两列，左列职位 / 右列姓名
3. 右侧「卡片预览」实时刷新，检查排版
4. 点 **下载 JPG** → 保存到相册/本地 → 发给打印店或发群里就行 🎯

### 💡 小贴士
- 默认背景色为团队统一色 `#FFD55E`（金黄色），不要改，除非特别要求
- 所有标题 / 内容颜色统一下拉调整，不要单个微调保持视觉一致
- **Talented Crew 最后一行必须填**（空着就填 `/`，避免版式错位）
- 字体：英文 Barlow Condensed / 中文 系统黑体，浏览器不需要额外安装

## 🏷️ 标签模板生成器 · 使用说明（Label Maker）

### 快速使用
1. 打开 **标签工具地址**（推荐 Chrome / Edge 桌面版）
2. **标签编辑**：日期 / 数量 / 项目 / 编号 4 个字段改一下就好
3. **标签预览**：实时看 400×300 打印效果
4. **标签打印**：
   - **有精臣打印机**：点「连接打印机」→ 选 B1 Pro / B2 Pro 等机型 → 点「直接打印」
   - **没有打印机 / 手机上用**：点「下载 JPG」→ 发电脑上打印即可
5. 标签内容自动记忆（下次打开自动恢复上次填的）

### 📱 兼容性
| 环境 | 支持情况 |
|---|---|
| Chrome / Edge 桌面版 (Win/Mac) | ✅ 完整支持：下载 + 蓝牙直连打印 |
| iOS Safari / 微信内置浏览器 | ✅ 可编辑 + 下载 JPG |
| Android Chrome | ✅ 可编辑 + 下载 JPG + 蓝牙打印（视机型） |
| TRAE / 无头浏览器 | ⚠️ 仅编辑 + 下载 JPG，蓝牙功能不可用 |

## 🔧 故障排查（员工自助）
**Q：名片 / 标签预览字体不一样？**
A：请用 **Chrome / Edge / Safari 最新版**打开，不要用 QQ 浏览器 / 360 浏览器，字体渲染会自动加载 Barlow Condensed。

**Q：打印机连不上？**
A：
1. 打开电脑 / 手机蓝牙
2. 打印机开机、装好标签纸
3. 用 Chrome 打开（不支持 Safari 蓝牙）
4. 仍搜不到：重启打印机，清空系统蓝牙配对列表重试

**Q：下载的 JPG 模糊？**
A：名片 800×1000 4:5（约 223dpi，2×3 寸照片纸刚好），标签 400×300 精臣官方标准尺寸。如店家要求更高 dpi，让他们按比例放大即可，源文件无损。
