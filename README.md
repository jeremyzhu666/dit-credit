---

## 🎴 一步到位使用流程
1. 打开上面的工具地址
2. 左侧改字段（预填默认值已经给你写好，不用每次重填）：
   - **外观**
     - 背景色（默认团队色 `#FFD55E`，没特殊要求别动）
     - Logo 文字（默认 *KK*，1–3 个字符）
     - 标题色 / 内容色（保持默认灰+深黑即可，需要特殊风格再改）
   - **第一部分 · DIT Studio**：团队名称（默认 *KK SH*，本场项目改成对应 DIT Team）
   - **第二部分 · PROJECT**：项目名称（默认 *Commercial - AUDI*，如 *EV - AUDI E7X Launch PV*）
     - ☑︎ 下方 Commercial 开关：商业项目保持打勾，学生/独立项目取消
   - **第三部分 · Talented Crew**：三行两列，**左边职位 / 右边姓名**
     - 三个必填，空行填 `/` 避免版式错位
3. 右侧「卡片预览」**实时刷新**，检查排版对齐
4. 点绿色 **「下载 JPG」** → 图片保存到本地 → 发群里 / 发打印店即可 🎯

---

## 📐 版式规范（不用改，记住这些就对了）
- 画布比例 **4 : 5 竖版**（800×1000，约 223 dpi，2×3 寸照片纸刚好）
- 英文字体 **Barlow Condensed** / 中文系统黑体，Chrome/Edge/Safari 自动加载，无需安装
- 垂直间距统一 50px，三框 / Logo / 底部留白对称对齐
- 颜色：默认背景 `#FFD55E` / 标题 `#494E57` / 内容 `#1F2328`（团队统一）

---

## 💡 小贴士
- 三行 Talented Crew 最后一行距框底严格 50px，不要删除空行，用 `/` 占位
- 项目名过长会自动缩小字号保证不越框，手动改短更美观
- 背景色/标题色/内容色三个下拉改完 **三个框 + Logo 一键同步变色**，不用单个改
